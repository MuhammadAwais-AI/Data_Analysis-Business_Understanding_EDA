# 🛒 Online Retail II Dataset - Exploratory Data Analysis

## 🎯 1. Objective of the Task
A retail company wants to understand customer purchase behavior before investing in a recommendation system. 

As a Data Analyst, the goal of this project is to:
- 📊 Explore the provided dataset
- 🔍 Identify patterns and data quality issues 
- 📈 Produce a complete Exploratory Data Analysis (EDA) report

The EDA will help the company understand:
1. **Who** its customers are 👥
2. **Which** products sell the most 🏆
3. **Which** countries generate the most revenue 🌍

## 📦 2. Dataset
- **Name**: Online Retail II Dataset
- **Source**: UCI Machine Learning Repository
- **Link**: [https://archive.ics.uci.edu/ml/datasets/Online+Retail+II](https://archive.ics.uci.edu/ml/datasets/Online+Retail+II)
- **Description**: Real transaction data from a UK-based online retailer covering the years 2009-2011.  
  Includes invoices, product descriptions, quantities, prices, and customer IDs.
